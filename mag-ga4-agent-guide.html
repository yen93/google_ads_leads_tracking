MAG GA4 Agent

On-demand Google Analytics & Google Ads reports, right inside the dashboard

The MAG GA4 Agent lets anyone on the team ask a plain-English question about our website traffic and Google Ads performance and get a live answer inside the dashboard — no spreadsheets, no logging in to Google Analytics, and nothing to install. You type a question, click a button, and a table comes back in a minute or two.

What it is

The GA4 Agent is a tab in the MAG Metrics dashboard. Ask it about our Google Analytics 4 and Google Ads numbers and it pulls the figures live and shows them as a table — so you don’t have to open Google Analytics or wait for a report.

Typical things it can answer:

  • How many Google Ads conversions we had in a period.
  • Which campaigns drove the most sessions and conversions.
  • A breakdown of all traffic sources (not just Google Ads).
  • Sessions, users and conversions by source & medium over a time window you choose.

How to use it

It takes about a minute. No technical knowledge needed.

Figure 1 — the whole flow from your side.

  1. Open the dashboard and sign in with your @myadventuregroup.com.au email — the same login you use for the other dashboard pages.
  2. Click the GA4 Agent tab along the top.
  3. Type your question in plain English in the box — or click one of the example chips to fill it in for you.
  4. Click the ⚡ GA4 On-Demand Report button.
  5. Wait about 1–2 minutes. The status moves from queued to running to done, and the answer appears as a table right below.

Tip: you can also press Ctrl+Enter (Cmd+Enter on a Mac) to run your question.

What you can ask

Write your question the way you’d say it out loud. Two things help the agent give you exactly what you want:

  • A time window — e.g. “last 7 days”, “last 30 days”, “last 90 days”, or “this year”. If you don’t say, it uses the last 30 days.
  • Google Ads only, or everything — say “Google Ads” (or “paid”) to focus on ads, or “all traffic / all sources” for the full picture.

Example questions:

  • “Google Ads conversions in the last 30 days”
  • “All traffic sources last 7 days”
  • “Which Google Ads campaigns performed best over the last 90 days?”
  • “Sessions and conversions by source this year”

Good to know

  • It takes a minute or two. Each question spins up a fresh, secure session to run the query — that’s why it’s not instant.
  • The numbers are live from Google Analytics 4 at the moment you ask.
  • Anyone signed in to the dashboard can use it — there’s nothing to set up per person and nothing to install.
  • If it shows an error, just try again. If it keeps failing, let the dashboard admin know.

How it's built

For the curious, here’s what happens behind the button. Your question and its answer are passed through a small shared table, so the heavy lifting (and the Google credentials) stay safely on the server — never in your browser.

Figure 2 — the end-to-end pipeline.

The pipeline, step by step

  1. GA4 Agent tab (your browser) — takes your question and shows the result.
  2. Dashboard backend (Google Cloud Run) — saves the question as a “pending” request and triggers the worker.
  3. Supabase table — the shared hand-off that holds the question and, shortly after, the answer.
  4. Claude cloud routine — a secure cloud session that picks up the request, runs the query, and writes the answer back.
  5. Google Analytics 4 — the live source the routine reads the numbers from.

Tech stack

  • Front end: a plain HTML/JavaScript tab in the MAG Metrics dashboard.
  • Back end: Node.js / Express on Google Cloud Run (with the dashboard’s email login).
  • Hand-off store: Supabase (PostgreSQL) — the same database the other dashboard pages use.
  • Worker: a Claude Code cloud routine running a small Python script.
  • Data source: the Google Analytics 4 Data API, read with a read-only service account.

A note on security

The Google Analytics key lives only inside the cloud worker’s environment, and the token that triggers the worker stays on the dashboard server. Neither is ever sent to your browser, and the service account can only read analytics — it can’t change anything.
