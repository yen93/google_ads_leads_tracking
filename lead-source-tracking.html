Lead Source Tracking

How we identify where ActiveCampaign leads came from

The Lead Source Tracking tab on the MAG dashboard shows, for every recent ActiveCampaign contact, the marketing channel they arrived from and the conversion they made — by joining Google Analytics (GA4), Calendly and ActiveCampaign. This guide explains what the tab shows, how a lead is matched to a source, and how the whole thing is built.

What the tab shows

The Lead Source Tracking tab lists recent ActiveCampaign contacts and, where we can work it out, the marketing channel each one came from and the conversion they made. Each row is one contact:

  • Created — when the contact was created in ActiveCampaign.
  • AC ID / Email — who the contact is.
  • Channel — the traffic source they arrived from (e.g. google / cpc).
  • Conversion Action — the website event that marked them as an enquiry.
  • Confidence — how sure we are of the match (high / medium / low / none).
  • Δ (s) and Matched At — the time gap and moment used for the match.

Cards across the top total the leads from each key channel: Paid Google (google / cpc), Paid Bing (bing / cpc) and Organic search (google / organic and bing / organic). Hover any Channel, Conversion Action or Confidence value for a plain-English explanation and a link to this guide.

Channels — where the lead came from

A lead's Channel is the traffic source Google Analytics (GA4) attributed to their visit, shown as source / medium. GA4 works this out automatically for every visit — from the ad click, the link's UTM tags, the referring website, or the search engine. The values you'll see:

  • google / cpc — a paid Google Ads click.
  • bing / cpc — a paid Microsoft / Bing ad click.
  • google / organic — a free click from Google search results.
  • bing / organic — a free click from Bing search results.
  • ActiveCampaign / email — a click from one of your ActiveCampaign emails.
  • myadventuregroup.ac-page.com / referral — a click through from your own ActiveCampaign-hosted landing pages.
  • linkedin.com / referral — a click from a link on LinkedIn.
  • teams…microsoft / referral — a link opened in Microsoft Teams.
  • (direct) / (none) — no source detected (typed URL, bookmark, or an untagged link).

Paid and email channels rely on the link being tagged; referral, direct and organic are detected automatically. A few referrals such as ads.google.com and tagassistant.google.com are internal / preview-tool artifacts, not real visitors.

Conversion actions — what the lead did

The Conversion Action is the GA4 event that marked the visitor as an enquiry, and it tells you which website form they used:

  • calendly_form_submit — booked a Calendly consult / discovery call.
  • form_submit — a generic site form (careers, Executive X, free-gift opt-in, free consult, team building, home).
  • form_submissions — the Contact-page form.
  • Contact_Form_Submit_Alt — the alternate contact / speaking-request form.
  • Form_submission_thankyou_1 — an enquiry form (the enquiry thank-you page).
  • subscribe — a newsletter / email opt-in.
  • free_gifts_opt_ins — the free-gift opt-in form.

Channel and Conversion Action describe two different things about the same visit: Channel is how they arrived; Conversion Action is what they did. Both come from the same GA4 event.

How a lead is matched

No single system holds both the identity and the source, so two are joined:

  • Calendly → ActiveCampaign by email — the booking's email also exists as an AC contact. This is an exact, reliable match.
  • GA4 → ActiveCampaign by timestamp — a website form event and the AC contact it created are the same action, seconds apart, so they're matched when their times fall within ±5 minutes of each other.

Figure 1 — one real action is logged in both GA4 and ActiveCampaign, then matched by time so the contact inherits the channel and conversion action.

The channel is not a separate click event — it's an attribute of the session that the conversion event already carries. The timestamp match simply works out which ActiveCampaign contact that anonymous GA4 event belongs to.

Confidence levels

Every match carries a confidence rating:

  • High — an exact Calendly email match, or a GA4 time match within 90 seconds with only one possible source in the window.
  • Medium — a GA4 time match that was 90–300 seconds away, or within 90 seconds but with several possible sources in that minute.
  • Low — a GA4 time match that was both ambiguous and 90–300 seconds away.
  • None — no source could be matched to the contact.

How it's built

The dashboard does no live lookups when you open the tab — a background job pre-computes the matches into a Supabase table, and the dashboard just reads it. End to end:

Figure 2 — the end-to-end pipeline from the data sources to the dashboard tab.

  • GA4 Data API — pulls website conversion events by the minute, with each event's channel (source / medium).
  • Calendly API — pulls bookings (invitee email + time).
  • ActiveCampaign contacts — already mirrored into Supabase (email + created time).
  • map_ga4_ac.py — the matcher: Calendly by email, GA4 by timestamp, with a confidence score.
  • Supabase cache — the pre-computed result table the tab reads.
  • Dashboard — an Express API serves the table to the plain-HTML Lead Source Tracking page.

Tech stack

  • Python — the matcher and the GA4 / Calendly pulls.
  • Google Analytics 4 (GA4 Data API), Calendly API, ActiveCampaign — the data sources.
  • Supabase (PostgreSQL) — stores the mirrored contacts and the pre-computed cache.
  • Node.js / Express on Google Cloud Run — the dashboard service.
  • Plain HTML / CSS / JavaScript — the dashboard pages (no build step).

Limits & what's next

  • Phone and email-link clicks can't be identified. A tap on a tel: or mailto: link captures no email and creates no contact, so those enquiries stay anonymous.
  • Timestamp matches are probabilistic. They're reliable because lead volume is low, but a GA4-time match is a best estimate, not a certainty.
  • The cache covers recent contacts only — a long-standing AC contact who books today may fall outside its window.
  • Google Ads isn't connected yet — it needs admin access to the ads account (currently billing-only). GA4 already gives the paid-click channel and campaign.

The durable fix for exact, per-lead attribution is to capture the Google click id (gclid) and UTM tags into hidden fields on every web form (and Calendly), stored on the ActiveCampaign contact. Then each lead carries its own verified source — no timestamp matching required.
