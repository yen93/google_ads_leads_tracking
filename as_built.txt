PURPOSE
Answer "which leads/deals come from Google Ads" from data, and power the
self-service "MAG GA4 Agent" tab on the MAG dashboard. GA4 gives aggregate
Google Ads volume; per-deal attribution would require a gclid captured into
ActiveCampaign (none exists today).

SCRIPTS (this repo)
- scripts/ga4_routine.py — cloud-friendly GA4 pull. Reads the service-account key
  from env var GA4_SA_JSON_B64 (base64) or GA4_SA_JSON_CONTENT (raw JSON) or
  GA4_SA_JSON (file path). Args: --days, --google-ads-only, --limit. Prints a
  markdown table (source/medium/campaign × sessions/conversions/users). This is
  the script the cloud routine runs.
  Requires: GA4_PROPERTY_ID + one of the key vars (in the routine's cloud env;
  locally in .env).
- scripts/ga4_pull.py — local GA4 report (reads key file GA4_SA_JSON); writes
  output/ga4_source_medium_{30,90}d.csv. Requires: GA4_PROPERTY_ID, GA4_SA_JSON.
- scripts/ac_check_lead_source.py — one-off audit: pulls all AC deals + the
  Lead-Machine source / lead-source fields, reports whether Google Ads is
  identifiable per deal (verdict 2026-10-02: no). Requires: AC_API_URL,
  AC_API_TOKEN. Writes output/ac_lead_source_*.csv.
- scripts/google_ads_auth.py — one-time OAuth to mint a Google Ads API refresh
  token. Requires: a Desktop OAuth client JSON (secrets/oauth_client.json).
- scripts/google_ads_pull.py — Google Ads campaign + gclid pull (not yet used;
  needs a developer token). Requires: secrets/google-ads.yaml, GADS_CUSTOMER_ID.
