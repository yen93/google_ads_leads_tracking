HOW TO ACTUALLY CAPTURE THE LINKS GOING FORWARD
-----------------------------------------------
In GTM, add link_url (and link_text) as event parameters on the click_to_call and
email_link_clicks tags, and register them as custom dimensions in GA4. After that,
the tel: number and mailto: address will appear in the same query used here.


METHOD / HOW TO RE-RUN
----------------------
Queried the GA4 Data API (BetaAnalyticsDataClient) with:
  - dimension filter eventName = <event>
  - dimensions: eventName x {linkUrl, pageLocation, pagePath, linkText, linkDomain,
    customEvent:event_label, customEvent:event_category}
  - metric: eventCount
  - date range: 90daysAgo..today
Auth: service account service_account_json_key_claudegwscli-502400-3a7969b176ed.json
(Viewer on GA4), same pattern as scripts/ga4_pull.py.
